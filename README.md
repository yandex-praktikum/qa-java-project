# Дипломный проект часть 2
## Задание 1. Юнит-тесты для [Stellar Burgers](https://stellarburgers.education-services.ru/)
### Был покрыт тестами класс _Burger_ с покрытием в 100%

#### Технологии, используемые при выполнении проекта:
* Среда разработки IntelliJ IDEA
* Java 11, Maven 3.8.1
* Библиотеки: JaCoCo 0.8.7, Mockito 4.8.0, JUnit 4.13.2

#### Установка и запуск: 

``` shell
    git clone https://git@github.com:DmrGbv/Diplom_1.git
    cd Diplom_1
    
    mvn clean test
```
