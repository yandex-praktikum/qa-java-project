# 🍔 Stellar Burgers: Unit Tests

Проект содержит модульные (юнит) тесты для проверки бизнес-логики приложения **"Stellar Burgers"**.
Основной упор сделан на тестирование класса `Burger`: добавление ингредиентов, расчет стоимости и печать чека.

---

## 🛠 Стек технологий

| Технология | Версия  | Назначение |
|------------|---------|------------|
| **Java** | 11      | Язык программирования |
| **Maven** | 3.9.12 | Управление зависимостями и сборка |
| **JUnit** | 4.13.2  | Фреймворк для тестирования |
| **Mockito** | 4.8.0   | Создание мок-объектов и стабов |
| **JaCoCo** | 0.8.8   | Анализ покрытия кода тестами |

---

## 🧪 Что протестировано

В соответствии с заданием, покрыт тестами класс `Burger`.

1.  **BurgerTest.java** — Основные проверки логики с использованием моков:
    *   Установка булочки.
    *   Добавление и удаление ингредиентов.
    *   Перемещение ингредиентов внутри списка.
    *   Формирование текста чека (Receipt).
2.  **BurgerPriceTest.java** — Параметризованный тест:
    *   Расчет полной стоимости бургера (Булка * 2 + Ингредиенты).

**🎯 Итоговое покрытие кода (Line Coverage) класса Burger — 100%.**

## 🚀 Как запустить тесты

Для запуска всех тестов выполните команду в терминале:

```bash
mvn clean test
```

## 📊 Отчет о покрытии (JaCoCo)
Чтобы сгенерировать отчет о покрытии кода
выполните команду:

```bash
mvn clean verify
```
