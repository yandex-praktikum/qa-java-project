# Praktikum: Unit Testing with JUnit and Mockito

Проект по написанию unit-тестов с использованием JUnit 4 и Mockito. Включает инструментацию покрытия кода с помощью
JaCoCo.

## 🛠 Технологии и зависимости

| Компонент | Версия |
|-----------|--------|
| Java      | 11     |
| Maven     | 3.9+   |
| JUnit     | 4.13.2 |
| Mockito   | 5.14.2 |
| JaCoCo    | 0.8.7  |

## ▶️ Как запустить тесты

Выполните в терминале из корня проекта:

```bash
mvn clean verify
