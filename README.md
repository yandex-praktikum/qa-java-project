# Яндекс Практикум - Тестирование класса Burger
Проект для тестирования класса `Burger` с использованием JUnit 4, Mockito и JaCoCo.

### Используемые технологии:
- **JUnit 4.13.2** 
- **Mockito 4.11.0** 
- **JaCoCo 0.8.7**
  Проект обеспечивает **100% покрытие кода** класса `Burger`.
### Запуск
Для запуска тестов используйте mvn test
Для генерации отчетов используйте  mvn clean verify
