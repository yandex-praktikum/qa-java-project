# Stellar Burgers API Tests

Этот проект включает в себя набор автотестов для API приложения **Stellar Burgers**. Тесты предназначены для проверки функциональности различных эндпоинтов, таких как создание пользователей, создание заказов, аутентификация и управление учетными записями пользователей.

## Описание

Проект использует **RestAssured** для тестирования REST API, **JUnit 4** для организации тестов, и **Allure** для генерации отчетов. Тесты включают как позитивные, так и негативные сценарии, чтобы обеспечить правильную работу API.

## Структура API

1. **Получение данных об ингредиентах**
    - **GET** `/api/ingredients`
    - Ожидаемый ответ: список ингредиентов.

2. **Создание заказа**
    - **POST** `/api/orders`
    - Тело запроса:
      ```json
      {
        "ingredients": ["ingredient_id_1", "ingredient_id_2"]
      }
      ```
    - Возможные ошибки:
        - **500 Internal Server Error** при невалидном хеше ингредиента.
        - **400 Bad Request** если ингредиенты не переданы.

3. **Восстановление пароля**
    - **POST** `/api/password-reset`
    - Тело запроса:
      ```json
      {
        "email": "user@example.com"
      }
      ```

4. **Создание пользователя**
    - **POST** `/api/auth/register`
    - Тело запроса:
      ```json
      {
        "email": "user@example.com",
        "password": "password123",
        "name": "Username"
      }
      ```

5. **Авторизация**
    - **POST** `/api/auth/login`
    - Тело запроса:
      ```json
      {
        "email": "user@example.com",
        "password": "password123"
      }
      ```

6. **Получение информации о пользователе**
    - **GET** `/api/auth/user`
    - Требуется передача **Authorization token** в заголовке.

## Сценарии тестирования

Тесты в проекте покрывают следующие случаи:

- **Создание пользователя**:
    - Уникальный пользователь.
    - Пользователь с уже зарегистрированным email.
    - Отсутствие одного из обязательных полей.

- **Логин**:
    - Вход под существующим пользователем.
    - Вход с неверным логином и паролем.

- **Создание заказа**:
    - Заказ с авторизацией.
    - Заказ без авторизации.
    - Заказ с ингредиентами.
    - Заказ без ингредиентов.
    - Заказ с невалидным хешем ингредиентов.
