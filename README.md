# **Автоматизация тестов для приложения Stellar Burgers**

**Задание 1. Юнит-тесты**

Этот проект содержит набор юнит-тестов для класса приложения бургерной "Burger"

Тесты написаны с использованием JaCoCo, Mockito, JUnit 4, а так же параметризованных тестов для проверки корректной работы логики приложения.

Используемые технологии: 

| технология | версия |
|------------|--------|
| Java       | 11     |
| Junit      | 4.13.2 |
| Maven      | 3.8.1  |
| Mockito    | 5.20.0 |
| Jacoco     | 0.8.14 |


Для запуска тестов используйте команду: mvn clean test

Посмотреть отчет о покрытии: mvn jacoco:report

Отчет появится в директории target/site/jacoco/index.html
