# Task_1. Итоговый дипломный проект по курсу "Автоматизатор тестирования на Java". UNIT-тесты
# Автоматизированные UNIT-тесты для логики учебного сервиса Stellar Burgers

## Технологии
* Java 11 — целевая версия языка для компиляции.
* Maven — инструмент автоматизации сборки и управления зависимостями.
* JUnit 5 (Jupiter) 5.10.0 — современный фреймворк для написания и запуска тестов.
* REST Assured 5.3.1 — инструмент для тестирования и валидации REST сервисов.
* Mockito 4.11.0 — библиотека для создания мок-объектов и изоляции тестируемого кода.
* Jackson DataBind 2.15.2 — библиотека для работы с JSON (маппинг объектов в JSON и обратно).
* JaCoCo 0.8.10 — плагин для измерения и генерации отчетов по покрытию кода тестами (Code Coverage).

### Что сделано:
1. Покрыты тестами классы Bun, Burger, Ingredient, IngredientType.
2. Использованы моки, стабы, параметризация.
3. Процент покрытия не ниже 70%.
   Примечание: класс Database содержит только константные данные для инициализации 
   и не несёт бизнес-логики, поэтому он исключён из метрик.
