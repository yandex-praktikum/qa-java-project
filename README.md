# Дипломный проект. Часть 1: Юнит-тестирование

Репозиторий содержит юнит-тесты для проверки веб-приложения по сборке бургеров Stellar Burgers.

## Описание проекта
Покрыто тестами приложение со следующей структурой:
* `Burger` — основная логика сборки бургера, расчёта стоимости и формирования чека.
* `Bun` — модель булочки.
* `Ingredient` и `IngredientType` — модели ингредиентов и их типов.
* `Database` — имитация базы данных.

## Что было сделано:
1. **Юнит-тесты (`BurgerTest`)**: покрыты методами проверки установки булок, добавления, удаления и перемещения ингредиентов. Написание тестов велось в изоляции с использованием **Mockito** (создание моков и стабов).
2. **Параметризованные тесты (`BurgerPriceParameterizedTest`)**: реализован отдельный класс для проверки метода `getPrice()`. Протестированы различные тестовые комбинации ингредиентов (отталкивая от базы данных) и цен на реальных объектах.
3. **Настройка тестового покрытия (JaCoCo)**: в `pom.xml` интегрирован плагин JaCoCo, исправлены конфликты кодировки для корректной генерации HTML-отчёта. Достигнуто **100% покрытие** класса `Burger`.

## Запуск тестов и генерация отчёта
Для запуска тестов и автоматического создания отчёта JaCoCo выполните команду:
```bash
mvn clean test
```
После успешного прохождения тестов отчёт будет доступен в папке:
`target/site/jacoco/index.html`
