Задание 1. Юнит-тесты

1. Настройка проекта
Подключены необходимые библиотеки: JaCoCo (для проверки покрытия кода), Mockito (для создания моков и стабов), JUnit 4 (для написания тестов)

Настроен Maven-проект с корректными зависимостями

2. Написание юнит-тестов для класса Burger
Разработано 13 тестовых методов, покрывающих всю функциональность класса:

Тестирование основных методов:

testSetBuns() - проверка установки булочки

testAddIngredient() - проверка добавления ингредиента

testRemoveIngredient() - проверка удаления ингредиента по индексу

testRemoveIngredientInvalidIndex() - проверка удаления с неверным индексом

Тестирование расчета цены:

testGetPriceWithBunAndIngredients() - расчет с булочкой и ингредиентами

testGetPriceWithoutBun() - расчет без булочки

testGetPriceEmptyBurger() - расчет для пустого бургера

Тестирование формирования чека:

testGetReceiptFormat() - проверка формата и содержания чека

Параметризованные тесты:

testBunPriceParameterized() - тестирование различных цен булочек (1.0, 2.5, 3.99, 0.0, 100.0)

Тесты с использованием моков:

testAddIngredientsFromDatabase() - мокирование Database и проверка добавления ингредиентов

testAddIngredientsFromDatabaseReturnsNull() - обработка ситуации с null от БД

testMockBunInteraction() - проверка взаимодействия с мок-булочкой

testMockIngredientInteraction() - проверка взаимодействия с мок-ингредиентом

3. Использование моков и стабов
Созданы моки для Database, Bun, Ingredient с помощью @Mock аннотации

Настроено поведение моков через when().thenReturn()

Проверены вызовы методов с помощью verify()

4. Параметризация
Использован @RunWith(Parameterized.class) для запуска параметризованных тестов

Переданы различные значения цен булочек для проверки корректности расчетов

5. Достижение 100% покрытия кода
Написаны тесты для всех публичных методов класса Burger

Покрыты граничные случаи (пустой бургер, null от БД, неверный индекс)

Проверены все ветвления условий (наличие/отсутствие булочки, валидность индекса)
