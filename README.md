## 🚀 Автоматизация тестирования Stellar Burgers — Часть 1
Дипломный проект по автоматизации тестирования для космической бургерной Stellar Burgers (Яндекс Практикум). В этой части реализовано 100% покрытие юнит-тестами основного бизнес-компонента сборки бургеров — класса Burger.

## 🛠️ Стек технологий и версий (pom.xml)

* Java: 11 (Compiler source/target)
* JUnit: 4.13.2 — фреймворк для тестирования
* Mockito Core: 4.8.0 — библиотека для создания моков и стабов
* Apache Maven Compiler Plugin: 3.8.1
* Apache Maven Surefire Plugin: 2.22.2 — плагин для запуска тестов
* JaCoCo Maven Plugin: 0.8.7 — плагин для генерации отчетов о покрытии кода


## 📊 Покрытие кода (Code Coverage)

* Класс Burger: 100% покрытие тестами по отчёту JaCoCo (Lines / Methods).


## 🧪 Реализованные тесты: BurgerTest ##
🔹 Юнит-тесты:
Изолированное тестирование методов управления бургером с использованием моков:

* setBunsTest — проверка успешной установки космической булочки.
* addIngredientTest — корректное добавление ингредиента в список бургера.
* removeIngredientSuccess — безопасное удаление ингредиента по индексу с предварительным наполнением списка.
* moveIngredientSuccess — проверка изменения порядка ингредиентов в списке (смещение позиций sauce и salad).
* getBurgerReceiptSuccess — валидация форматированного чека с реальными космическими данными из API (Краторная булка N-200i, Кристаллы марсианских альфа-сахаридов).


## 🔹 Параметризованные тесты: BurgerPriceParameterizedTest ##
Проверка математической логики подсчета стоимости бургера (Цена = Булочка * 2 + Ингредиент) на актуальных данных, полученных через API Stellar Burgers:

* Кейс 1: Булка R2-D3 (988.0) + Соус Spicy-X (90.0) = 2066.0
* Кейс 2: Булка N-200i (1255.0) + Говяжий метеорит (3000.0) = 5510.0
* Кейс 3: Булка R2-D3 (988.0) + Салат Экзо-Плантаго (4400.0) = 6376.0

## 🏃 Запуск тестов и генерация отчета
Для запуска тестов и генерации отчета JaCoCo выполните в терминале IDEA команду:
* mvn clean verify
* После сборки интерактивный отчет будет доступен в папке target/site/jacoco/index.html
