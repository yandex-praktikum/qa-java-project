# Stellar Burgers UI Tests

Проект автоматизированных UI тестов для приложения **Stellar Burgers**, разработанных с использованием **Selenium WebDriver** и **JUnit**. Для генерации отчетов используется **Allure**.

## Стек технологий
- **Java 11** — язык программирования
- **Selenium WebDriver** — инструмент для автоматизации веб-приложений
- **JUnit 4** — фреймворк для написания тестов
- **Allure** — для генерации и отображения отчетов
- **Maven** — для сборки проекта и управления зависимостями

## Установка и запуск
1. **Клонировать репозиторий:**
    ```bash
    git clone https://github.com/nastymavr/QA-java-diplom
    ```

2. **Перейти в папку проекта:**
    ```bash
    cd <папка с проектом>
    ```

3. **Установить зависимости:**
    ```bash
    mvn install
    ```

4. **Запустить тесты:**
    ```bash
    mvn test
    ```

5. **Генерация и просмотр отчета Allure:**
    ```bash
    mvn allure:serve
    ```

## Структура проекта
- **src/** — исходный код тестов
- **target/** — скомпилированные файлы и отчеты Allure
- **pom.xml** — конфигурация Maven для зависимостей и плагинов
- **README.md** — документация проекта
