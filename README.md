# Burger unit tests

JUnit 4, Mockito, parameterized tests, and JaCoCo coverage for `praktikum.Burger`.

```shell
mvn clean verify
```

The JaCoCo check requires 100% line and branch coverage for `Burger`. The HTML report is generated in `target/site/jacoco`.

Test run summary is documented in [reports/test-report.md](reports/test-report.md).
