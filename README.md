# 🍔 Stellar Burgers: Unit тесты

Проект содержит модульные (юнит) тесты для проверки бизнес-логики приложения "Stellar Burgers".
Покрывает функциональность создания бургера, расчета стоимости и работы с ингредиентами.

## 🛠 Стек технологий

| Технология | Версия | Назначение |
|------------|--------|------------|
| Java | 11 | Язык программирования |
| Maven | 3.8+ | Сборка проекта |
| JUnit | 4.13.2 | Тестовый фреймворк |
| Mockito | 4.8.0 | Создание мок-объектов |
| JaCoCo | 0.8.8 | Анализ покрытия кода |

## 🧪 Что протестировано

1. **Bun** — модель булочки (создание, геттеры).
2. **Ingredient** — модель ингредиента (тип, цена, название).
3. **Burger** — основная логика (добавление/удаление ингредиентов, расчет цены, генерация чека).
4. **BurgerPrice** — параметризованные тесты расчета стоимости.

**Покрытие кода тестами составляет 100%.**

## 🚀 Запуск тестов

Для запуска всех тестов выполните команду в терминале:

```bash
mvn clean test
```
## 📊 Отчет о покрытии (JaCoCo)
Чтобы сгенерировать отчет о покрытии кода
выполните команду:

```bash
mvn clean verify
```
