# Diplom_1 - Задание 1. Юнит-тесты для Stellar Burgers

## Зависимости проекта

### Основные технологии

* **Java** - версия 11
* **JUnit** - версия 4.13.2 (фреймворк для юнит-тестирования)
* **Mockito** - версия 3.12.4 (библиотека для создания моков)
* **JaCoCo** - версия 0.8.13 (инструмент для измерения покрытия кода тестами)

### Примечания

* Все зависимости настроены через Maven
* JaCoCo используется для отслеживания покрытия тестами
* Mockito интегрирован для упрощения написания тестов
* JUnit является основным фреймворком для тестирования

### Установка

Для работы с проектом рекомендуется использовать Java 11 или более новую версию. Все остальные зависимости автоматически подтянутся при сборке через Maven.
