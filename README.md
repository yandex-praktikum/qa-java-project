
# Diplom_1
## Автоматизированные тесты для программы заказа бургера в Stellar Burgers.

### Описание

Набор автоматизированных тестов на Java для проверки класса Burger
* тестирование методов классов Burger;
* использование набора данных для тестирования класса Burger.

### Технологии, зависимости и плагины
* Java 11
*  Maven
* JUnit 4.13.2
* Mockito
* AssertJ
* jacoco-maven-plugin 0.8.7
* maven-surefire-plugin 2.22.2

 

### Запуск тестов

```shell
mvn clean test
