# QA-java-diplom-1

Юнит-тесты для класса Burger с анализом покрытия кода (Jacoco).

## 📦 Технологии
| Компонент       | Версия   |
|-----------------|----------|
| Java            | 11       |
| JUnit           | 4.13.2   |
| Mockito         | 3.12.4   |
| Jacoco          | 0.8.7    |

## 🚀 Запуск тестов
```bash
mvn clean test
```
## 📊 Отчёт о покрытии кода (Jacoco)
Сгенерировать отчёт:

```bash
mvn verify
```
Открыть:
target/site/jacoco/index.html
