# Stellar Burgers - Юнит тесты

Проект для тестирования функциональности заказа бургеров в системе Stellar Burgers.

## Технологии
- Java 11
- JUnit 4.13.2
- Mockito 4.11.0
- JaCoCo 0.8.8

## Запуск тестов
```bash
mvn clean test
```

## Отчет о покрытии
100% покрытие класса Burger юнит-тестами с использованием моков и параметризации.
