# Тестовый проект Stellar Burgers. Unit-тесты

## Описание

Этот проект представляет собой тестовое покрытие для программы, которая помогает заказать бургер в сервисе **Stellar Burgers**.  
В рамках проекта реализованы юнит-тесты с использованием таких инструментов, как Mockito, JUnit 4 и Jacoco.
---

## Используемые технологии

- **JUnit 4** — для написания юнит-тестов.
- **Mockito** — для создания моков и стабов в тестах.
- **Jacoco** — для измерения покрытия кода тестами.

---

## Структура проекта

- `src/main/java/praktikum` — основной код приложения.
- `src/test/java/praktikum` — тесты для классов приложения.
- `target/site/jacoco` — сгенерированный отчёт покрытия кода.
