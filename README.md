# Stellar Burgers Test Project

Этот проект содержит юнит-тесты для программы заказа бургеров в Stellar Burgers. Тесты покрывают класс `Burger` с использованием моков, стабов и параметризации.


## Зависимости
- JUnit 4
- Mockito
- AssertJ
- JaCoCo
