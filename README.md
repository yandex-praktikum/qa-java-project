# QA Java Diplom Project

Проект по автоматизации тестирования Java-приложения с использованием:

- JUnit 4
- Mockito
- JaCoCo
- Maven

## Структура проекта

- `/src` — исходный код и тесты
- `pom.xml` — зависимости и сборка Maven
- `.gitignore` — исключения файлов для Git
- `README.md` — документация проекта

## Запуск тестов

```bash
mvn clean test
