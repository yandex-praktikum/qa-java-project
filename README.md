# Тестовое покрытие класса Burger

## 1. Класс BurgerTests

Этот класс содержит обычные (непараметризованные) юнит-тесты, которые проверяют основные методы класса Burger.

### 1.1 setBun_shouldSetValidBunTest

Проверяет:
- булка устанавливается;
- ссылка в burger.bun совпадает с переданным моком.

### 1.2 addIngredient_ShouldIncreaseByOneTest

Проверяет:
- что после вызова addIngredient() размер списка ингредиентов увеличивается на 1.

### 1.3 addIngredient_ShouldAddToEndTest

Проверяет:
- что добавленный ингредиент попадает именно в конец списка burger.ingredients.

### 1.4 removeIngredient_ShouldDecreaseByOneTest

Проверяет:
- что после удаления ингредиента методом removeIngredient(index) общее количество ингредиентов уменьшается на 1.

### 1.5 removeIngredient_ShouldRemoveCorrectTest

Проверяет:
- что при удалении ингредиента по индексу удаляется именно тот элемент, который ожидался.

### 1.6 moveIngredient_ShouldMoveToNewIndexTest

Проверяет:
- что метод moveIngredient(int index, int newIndex) перемещает ингредиент с исходного индекса на указанный новый;
- после перемещения ингредиент занимает корректную позицию.

### 1.7 moveIngredient_ShouldPreserveCountTest

Проверяет:
- что при перемещении ингредиента размер списка ингредиентов остаётся неизменным.
Таким образом тест гарантирует, что метод выполняет именно перемещение, а не удаляет или дублирует элементы.

### 1.8 getPrice_ShouldReturnCorrectTotalPriceTest

Проверяет:
- правильность расчёта стоимости бургера методом getPrice():
  - цена булки учитывается дважды; 
  - добавляется цена каждого ингредиента; 
- итоговая цена совпадает с ожидаемой.

## 2. Класс BurgerGetReceiptParameterizedTest

Параметризованный тестовый класс, который проверяет форматирование чека, генерируемого методом: public String getReceipt()

### Каждый параметризированный сценарий задаёт:
- имя кейса (caseName),
- ожидаемую строку чека, 
- список ингредиентов (моки), 
- имя и цену булки.

### Проверяемые сценарии:
1. Только булки (нет ингредиентов)

Проверяется:
- корректное формирование заголовков и футера; 
- корректный расчёт итоговой цены; 
- формат строки Price: %f.

2. Булка + один соус

Проверяется:
- корректный вывод строки ингредиента вида:
  - = sauce ingredientName =;
- правильная итоговая цена.

3. Булка + начинка + соус

Проверяется:
- порядок ингредиентов в чеке;
- корректная вставка текста вида
  - = filling megaPatty =
  - = sauce sweetDip =; 
- итоговая цена бургера.
