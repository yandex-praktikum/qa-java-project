# Дипломный проект. Задание 1. Unit тестирование Stellar Burgers

### 🛠️ Стэк технологий:

Java 11, JUnit 4, Maven, Mockito, JaCoCo, AssertJ

### 📋 Описание задания:

Цель — покрыть юнит-тестами основной класс: `Burger`.
Используются моки, параметризация и отчёт о покрытии кода.

### 🚀 Для запуска тестов:

```bash
  mvn clean test
```

### 📊 Для генерации отчёта Jacoco:

```bash
  mvn jacoco:report
```

**Открыть отчёт можно по пути:**  
`target/site/jacoco/index.html`
